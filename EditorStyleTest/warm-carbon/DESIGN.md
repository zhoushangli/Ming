# Warm Carbon Ink

墨本来就是碳做的。骨架是工业的，笔触是墨的，琥珀是余火。

## 规则

- **配色：** 沿用 Warm Carbon，`tokens.json` 的 `color` 未改动。
- **笔触只出现在标志和横笔上。** 小尺寸下飞白看不见，其他控件不用笔触。
- **琥珀色只表示“活”的状态：** 选中、焦点、运行中，以及设置对话框的主按钮。
- **工业骨架：** 全部直角；面板是实色板，由 6px 接缝分隔；接缝和视口边缘带刻度，面板内部保持干净。
- **文字：** 全部英文，只用 JetBrains Mono Regular，靠颜色和大小写分层，不用粗体和字间距。
- **场景画布：** 保持 `#202020`，不染主题色。

## 顶栏

- 高 48px，所有 Dock 顶部对齐，不破格。
- 标志高约 46px，象牙白 `#ded9d0`，贴图 `assets/ming-glyph.png`（104×48）。
- 横笔高 34px，暖灰 `#514a40`，贴图 `assets/ming-beam.png`，从标志下方穿过，向右断墨并变淡。
- 横笔宽度取 720px 和“窗口一半减 40px”中较小的值，必须在 2D/3D 之前消失。贴图在 720px 宽时约 677px 处完全透明。
- 菜单文字压在横笔上，对比度不低于 6.2:1。

## 引擎还原

| 网页表现 | 引擎实现方向 |
| --- | --- |
| 面板、接缝、标尺刻度、网格、选中框 | `DrawRect` |
| 标志、横笔 | `DrawTextureRect`，需要 Alpha 混合（已有）；横笔宽度随窗口计算 |
| 菜单按钮压在横笔上 | 按钮常态不绘制背景 |
| 界面文字 | 已内嵌的 JetBrains Mono |
| 图标 | 可染色贴图走 `DrawTextureRectRegion` 的 color；SVG 的断笔空隙用蒙版实现，需转成纯路径或预渲染 |
| 界面缩放 | 统一 UI 缩放后重新布局 |

原生编辑器使用 `EditorThemeManager` 保存颜色、尺寸和控件状态；圆角、渐变和阴影不属于本轮迁移。图标由 `Code/MingEngine/Editor/GenerateBuiltinIcons.py` 离线转换并内嵌，运行时不依赖本网页目录。

## 图标

`icons/` 是当前图标库，共 254 个 SVG，`manifest.json` 记录每个图标的家族、颜色和是否抽象类。

- **形状跟随 Godot：** 16 网格；同一概念用同一形状，2D 和 3D 只换颜色，几何不同时才变形；同族共用母题。
- **断笔：** 物体分两层，主形表示它是什么，淡层（45%）表示补充信息，两层之间留 1px 空隙。动作图标只用一层。
- **颜色只跟继承走：** Node2D `#93d0dd`，Node3D `#a68bd4`，Control `#9fbea0`，其余节点和资源用 `muted`。抽象类用淡层加细轮廓。
- **圆润按大小分级：** 大色块半径 3–4，方框外角 2、内角直角，小部件 1；线条用圆头。

`icons.js` 是这些文件的内联副本，由 `tools/generate-icons.py` 生成；改完图标后要重新运行。`tools/verify.py` 会检查两边一致。场景树选中行保留类型色，只靠行背景表示选中；琥珀色图标只用于工具栏的开关状态。

## 树和新建节点

- **树的连接线：** 选中节点时，从每一层祖先到它画一条 1px 暗色实线（`--strong`），两端都不连死：竖线在父节点箭头下方留约 5px 再开始，横线停在图标前约 7px、箭头前约 5px。线只跟随选中项，不画整棵树的层级线。场景树、文件树和新建节点的类型树共用同一套逻辑。
- **Create New Node：** 由 Scene 面板的加号、右键菜单或 `Ctrl+A` 打开。左侧是收藏和最近使用，右侧是类型树和说明。支持搜索、方向键和回车，双击直接创建。抽象类显示为灰色，可以查看但不能创建。
