# Warm Carbon Ink assets

- `ming-glyph.png`, `ming-beam.png`: 2x RGBA textures generated by `tools/generate-brand.py` (seed 5). Rerun the script to regenerate; do not edit the bitmaps.
- `JetBrainsMono-Regular.ttf`: extracted byte-for-byte from `kNativeFontData` in the engine's embedded JetBrains Mono font (now stored in `Code/MingEngine/Scene/Resource/DefaultFontData.inc`), so the page uses the engine's font (Version 2.211, weight 400).
